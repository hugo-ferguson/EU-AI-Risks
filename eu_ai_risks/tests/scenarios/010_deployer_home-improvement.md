FR-01 - The system shall present the user with a predefined set of selectable moods (e.g., relaxed, focused, energetic, sleepy, social, romantic).

FR-02 - The system shall allow the user to select exactly one mood at a time as the input for generating a lighting suggestion.

FR-03 - The system shall use an AI model to map the selected mood to a recommended indoor lighting colour temperature value expressed in Kelvin (K) within the range 2000K to 6500K.

FR-04 - The system shall display the recommended colour temperature to the user as both a numeric Kelvin value and a descriptive label (e.g., “Warm White”, “Neutral White”, “Cool White”).

FR-05 - The system shall provide a visual preview of the recommended colour temperature on the user interface so the user can see the suggested lighting tone before applying it.

FR-06 - The system shall allow the user to accept the suggestion, reject it, or manually adjust the suggested value within the permitted range.

FR-07 - The system shall generate a new suggestion each time the user selects a different mood, with the updated recommendation displayed within 2 seconds of selection.

FR-08 - The system shall store the user’s accepted or manually adjusted settings for each mood and use this feedback to refine future suggestions for that user.
