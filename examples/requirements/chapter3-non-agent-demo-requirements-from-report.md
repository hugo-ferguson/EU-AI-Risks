# Chapter 3 Non-Agent Demo Requirements

This short requirements document is intended for testing the EU AI Act Chapter 3 risk assessment flow in non-agent mode.

## CH3-DEMO-1

The system shall ingest candidate resumes, cover letters, and application form responses for automated recruitment screening.

## CH3-DEMO-2

The system shall generate and display a candidate suitability score with an explanation of the main factors that influenced the score.

## CH3-DEMO-3

The system shall allow a human recruiter to review, override, or reject an automated ranking before a candidate is removed from consideration.

## CH3-DEMO-4

The system must log each automated score, ranking, explanation, recruiter override, final decision, and model version for audit review.
